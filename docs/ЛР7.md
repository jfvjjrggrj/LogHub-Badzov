### Разделитель из конфигурации
Парсер CSV принимает `char delimiter` через конструктор, а не хардкодит запятую.
Это позволяет переключаться между форматами (`,` / `;` / `\t`) правкой `appsettings.json`
без перекомпиляции — требование варианта 2.

### SQLite как приёмник
SQLiteSink реализует общий интерфейс `ILogSink` — это **Адаптер** (готовится к ЛР5).
Интерфейс SQLite (`Save(DateTime, int, string)`) несовместим с `ILogSink.Write(LogEntry)`,
поэтому адаптер преобразует `LogEntry` в параметры запроса.
